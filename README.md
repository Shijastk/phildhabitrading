# Phildhabi General Trading

Corporate B2B website for **Phildhabi General Trading**, focused on wholesale cosmetics, personal care, food and FMCG supply in Dubai and Abu Dhabi.

## Design direction

The layout takes inspiration from high-energy industrial corporate websites: strong navy/red geometry, overlapping capability cards, large photography, angled section cuts, process blocks, statistics and a prominent enquiry area. The content and visual composition are original to Phildhabi's trading business.

## Stack

- Static HTML
- Responsive CSS
- Vanilla JavaScript
- WhatsApp enquiry flow
- GitHub Pages workflow

## GitHub Pages

Deployment workflow: `.github/workflows/pages.yml`

Once GitHub Pages is enabled for the repository with **Source: GitHub Actions**, pushes to `main` deploy automatically.
